# Polybar configuration

A fast and easy-to-use status bar.

## Installation

Change the hardware configuration in the `/config/polybar/hardware.ini` file.

Execute the `install.sh` script.

```bash
./install.sh
```

## Custom modules

- Belgian Heating Oil Price
- Chrome Process
- Docker process
- Kernel version
- Node process
- Pacman update
- Tmux session
- VPN status
